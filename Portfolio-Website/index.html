About

Designer, student, and studio founder

I am Tibor Bari, a web designer in Toronto and the founder of Tiby Design Studio. I study software and web development at AOLCC Scarborough, in the Software and Web Developer program at Academy of Learning.

This site is the final portfolio for my CSS and Bootstrap coursework. The projects in the work section are the pages already in this repository, described from the files themselves.

Tiby Design Studio is the name of my design practice. Here it is introduced through work I can open and review: page structure, typography, responsive layout, and a Bootstrap cinema site.

Practiced in this repository

  • Semantic HTML and in-page navigation
  • CSS type, color, hover effects, and media queries
  • Layouts for phone, tablet, and desktop widths
  • Bootstrap 5 components with a custom theme
  • Forms with labels and required fields

Work

Course projects in this repository

Listed from the latest project to the earliest. Each card opens the original page with a relative link, so the same path works locally and on GitHub Pages under this repository.

Latest project

Academy Cinemas

A Bootstrap 5.2 cinema page with a collapsing navigation bar, a Now Playing menu, three movie cards, ticket selectors, and a contact form. Custom CSS sets the theater colors, the hero, and the cards. Bootstrap’s CSS and JavaScript load from a CDN, so that page needs a network connection.

  • HTML
  • Bootstrap 5.2
  • Custom CSS

Open Academy Cinemas

Simple Recipes

A recipe page with a sticky navigation bar, a CSS dropdown, a featured skillet pizza, and flip cards for pasta, chicken, pork, biscuits, fish, and dessert. The stylesheet uses Josefin Slab and Sacramento, hover states, and breakpoints from narrow phones through wide screens. About and contact sections follow the recipes.

  • HTML
  • CSS
  • Responsive

Open Simple Recipes

CSS Effects Challenge

A short page that loads Poppins from Google Fonts and scales a photograph on hover. The photograph comes from picsum.photos, so it appears when that remote image is available. The preview on this card is a local stand-in, not that photograph.

  • CSS
  • Google Fonts
  • Hover

The Pet Shop

A two-page site, home and contact, written with semantic HTML. The home page introduces cats, dogs, rabbits, guinea pigs, fish, and reptiles. The contact page has a message form and a newsletter checkbox. Photographs are credited in the project’s image credits file. This project does not include a separate stylesheet.

  • HTML
  • Two pages
  • Forms

Luxury Cars Gallery

A single HTML page in the One-Page Website folder. In-page links move between the introduction, a gallery of a Porsche, a Ferrari, and a Lamborghini, a contact form, and an embedded video. Styling is left to the browser.
